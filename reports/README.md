# Reports

Báo cáo sinh ra từ backtest/nghiên cứu (JSON/CSV/HTML) nằm ở đây và bị gitignore.

Mỗi báo cáo phải ghi rõ:

- experiment ID, strategy/model version, git commit/version code;
- config hash, data fingerprint, nguồn dữ liệu và khoảng thời gian;
- symbol/timeframe;
- giả định spread, slippage, commission và khớp lệnh;
- metric cùng trạng thái hoàn thành;
- dữ liệu là thực, fixture hay synthetic.

Không trình bày số liệu mô phỏng như kết quả giao dịch thật. Chưa có báo cáo nào được tạo.
