# Preset requirements

The actual `.set` files must be generated by AI only after compiling the EA and enumerating the real `input` variables. Do not invent `.set` keys.

Required presets per EA:

- `diagnostic_loose.set` — Strategy Tester diagnostics only; optional filters disabled in a recorded matrix; fixed finite volume; finite position/exposure caps.
- `baseline.set` — strategy's documented standard configuration.
- `risk_stress.set` — test cost/volatility/margin adverse assumptions.
- `demo_guarded.set` — all demo risk guards active and finite; runtime DEMO-only gate.
