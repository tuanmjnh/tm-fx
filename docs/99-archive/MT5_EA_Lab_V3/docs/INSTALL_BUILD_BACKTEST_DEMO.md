# Install, Build, Strategy Tester & Demo Runbook

## 1. What must exist before a bot can run

- MetaTrader 5 desktop terminal installed.
- MetaEditor 5 opened from the same terminal instance.
- Complete `.mq5` entrypoint and every referenced `.mqh`/resource file.
- Correct terminal data folder selected via MT5 `File → Open Data Folder`.
- For each EA: `.set`/preset generated from the actual input names in source.
- For Strategy Tester: available historical data for exact symbol/timeframe/date.

## 2. Place project files

Recommended layout in the correct MT5 data folder:

```text
MQL5/
  Experts/MT5_EA_Lab/<Strategy>/<Strategy>.mq5
  Include/MT5_EA_Lab/.../*.mqh
  Files/MT5_EA_Lab/...        # logs/state if code intentionally uses MQL5 Files
```

Do not copy only the main `.mq5` if it has `#include` dependencies. Keep relative include paths consistent or use the MQL5 `Include` path deliberately.

## 3. Compile

1. From the exact Exness MT5 terminal, open MetaEditor (`F4`).
2. Open the main EA `.mq5` file (not an `.mqh` dependency as the main program).
3. Compile (`F7`).
4. Confirm `.ex5` created and inspect the Errors/Toolbox log. Warnings must be reviewed.

MetaEditor can be used from an external IDE via command line. Official syntax examples:

```powershell
& 'C:\Path\To\metaeditor64.exe' /compile:'C:\Path\To\MQL5\Experts\MT5_EA_Lab\GridEA\GridEA.mq5' /log
```

Use the actual path discovered on the user's computer. Do not assume the install path. Add `/include:` only when external include root is actually needed and confirmed. Source: https://www.metatrader5.com/en/metaeditor/help/beginning/integration_ide

## 4. Strategy Tester — per EA

1. Open MT5 Strategy Tester (`Ctrl+R`).
2. Select one EA at a time.
3. Select exact Exness symbol name (suffix may exist), timeframe, date range and initial deposit/currency.
4. Confirm available history and wait for downloads/synchronization.
5. First run `diagnostic_loose` in a short period to verify data/signal/transaction pipeline.
6. Run `baseline` over a broader historical period.
7. Run `risk_stress` scenarios.
8. Export tester report and copy the exact input preset into the run folder.
9. If trades = 0, complete `NO_TRADE_DIAGNOSTICS.md` before editing the strategy.

Use `Every tick based on real ticks` when the required real tick history is available and the test requires granular SL/trailing/grid behavior. Use faster modeling modes only for smoke tests where appropriate. MetaTrader documents several modeling modes, data download, delays, spread and tester reports here: https://www.metatrader5.com/en/terminal/help/algotrading/testing

## 5. Demo forward verification — user initiated

The project supports a demo-only mode only if its account guard is implemented and verified. Before a user-run test:

- verify account type is DEMO;
- verify terminal/account/EA algo-trading permissions;
- verify exact symbol name and contract details;
- use a separate Magic Number and preset per EA;
- start with one EA and one symbol;
- monitor Experts/Journal and CSV logs;
- confirm the kill switch and restart/state recovery behavior;
- stop the test if order results, state, or risk counters disagree with the report.

The AI coding agent must not log into a broker, enable terminal trading permissions, or start demo execution on the user's behalf. It prepares the EA and runbook; the operator starts and monitors the demo test.

## 6. Troubleshooting quick table

| Symptom | First place to inspect |
|---|---|
| EA not in Navigator | wrong Data Folder or no `.ex5` |
| Compile cannot find `.mqh` | include graph/path incomplete |
| `OnInit` failed | first `LAB|ERROR` / init reason |
| No ticks | tester symbol/date/timeframe or test not started |
| Waiting for data forever | history sync/BarsCalculated/CopyBuffer |
| No BUY/SELL | direction diagnostics and closed-bar indexing |
| Signal exists, no request | filter/risk/sizing/margin reason code |
| Request rejected | actual trade retcode, filling mode, stops/freeze, volume |
| Tester works, demo guard blocks | account mode and runtime checks; never bypass a non-demo guard |
| State mismatch after restart | state schema, Magic Number and position reconciliation |

## 7. What counts as proof

- Compiler log from the actual MetaEditor executable.
- `.ex5` output timestamp/hash.
- Strategy Tester HTML/report and exact settings.
- Journal/Experts logs.
- `NO_TRADE_DIAGNOSIS.md` with counters.
- Demo forward-test log generated by a user-initiated test.

A screenshot of an EA attached to a chart, a README claim, or a source file existing is not proof that the EA compiles or trades in the tester.
